## 3. Powerlifting Science-Based Insights

### 3.1 RPE and Training Load Management

Based on research from [Progressive Rehab & Strength](https://www.progressiverehabandstrength.com/articles/rpe-in-powerlifting-what-is-rpe) and [Ripped Body](https://rippedbody.com/rpe/):

| Training Goal | Recommended RPE | Current Status |
|---------------|-----------------|----------------|
| Strength Focus | RPE 8-9 | Currently averaging 6.3 - can push harder |
| Hypertrophy | RPE 6-7.5 | Appropriate for volume work |
| Technique/Recovery | RPE 5-7 | Good during deloads |
| Competition | RPE 10 | Reserved for meet day |

**Reactive Fatigue Rule:** If any top set overshoots target by >0.5 RPE, cut one back-off set next week.

### 3.2 Block Periodization Structure

Based on [Juggernaut Training Systems](https://www.jtsstrength.com/periodization-powerlifting-definitive-guide/) and [Lift Vault](https://liftvault.com/periodization/block/):

**Optimal Block Structure:**
1. **Accumulation (4-6 weeks):** High volume, moderate intensity (60-75% 1RM)
2. **Transmutation (3-4 weeks):** Sport-specific, higher intensity (75-85% 1RM)
3. **Realization/Peaking (2-4 weeks):** Very low volume, max intensity (85-100% 1RM)

**Current Training Assessment:**
- Good block structure evident in data
- Appropriate intensity progression through blocks
- Meet prep shows proper tapering

### 3.3 Competition Preparation Guidelines

Based on [PMC Research](https://pmc.ncbi.nlm.nih.gov/articles/PMC7552788/):

**Evidence-Based Tapering:**
- Reduce volume by 30-70% in final 1-2 weeks
- Maintain intensity at ≥85% 1RM
- Short training cessation of 2-7 days before competition
- Use exponential or step taper model

Based on [Powerlifting Technique](https://powerliftingtechnique.com/squat-to-bench-press-ratios/) and [Strength Level](https://strengthlevel.com/):

## 6. Deployment Strategy

### 6.1 Streamlit Cloud Deployment

**Steps:**
1. Push code to GitHub repository
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect GitHub account
4. Select repository and branch
5. Set main file path: `src/app.py`
6. Deploy

**Configuration (.streamlit/config.toml):**
```toml
[theme]
primaryColor = "#FF6B6B"
backgroundColor = "#FFFFFF"
secondaryBackgroundColor = "#F0F2F6"
textColor = "#262730"
font = "sans serif"

[server]
headless = true
enableCORS = false
enableXsrfProtection = true
```

After deployment, you'll get a URL like:
