# Data Collection Suggestions for Future Training Insights

These are suggestions for additional data points to collect for more actionable insights.

## High Priority

### 1. Weekly Training Reflections
Add a column or notes section for each week with:
- How did training feel this week? (1-5 scale: Terrible → Great)
- Any technical breakthroughs or cues that clicked?
- What limited you this week? (fatigue, time, motivation, injury)
- Rate your recovery (1-5)

**Why:** Correlates subjective feel with objective performance.
Example: "Week felt hard (2/5) but hit PR - might be underestimating recovery"

### 2. Bodyweight Tracking
Add weekly morning bodyweight (ideally daily average):
- Helps identify if weight cuts affect performance
- Track bulk/cut phases against strength progress
- Important for competition weight management
- Can calculate relative strength metrics (kg lifted per kg bodyweight)

### 3. Readiness/Fatigue Score
Before each session, rate readiness (1-10):
- How recovered do you feel?
- Any soreness or tightness?
- Motivation level?

**Why:** Helps identify when to push vs back off, cumulative fatigue patterns, optimal deload timing.

## Medium Priority

### 4. Sleep Data
Track nightly sleep hours (even rough estimates help):
- Average sleep per night
- Quality rating (1-5)
- Correlate with RPE and performance

### 5. Video Links for Key Sets
Add a "Video" column for top sets:
- Link to form check videos for PRs
- Useful for technique analysis over time
- Can review competition attempts
- Great for identifying technical breakdown points

### 6. Life Stress Indicators
Weekly rating (1-5) of external stress:
- Work stress
- Sleep disruptions
- Travel/schedule changes

**Why:** Helps explain performance dips not related to training.

## Lower Priority (But Valuable)

### 7. Nutrition Markers
Simple weekly averages:
- Daily protein intake (g)
- Daily calories (rough estimate)
- Hydration quality

### 8. Injury/Pain Log
Track any niggles or issues:
- Location (e.g., "left shoulder", "lower back")
- Severity (1-5)
- What aggravates it
- What helped

### 9. Competition Attempt Selection Data
For future meets, record:
- Planned openers vs actual
- Decision-making rationale for each attempt
- Warmup room weights and how they felt
- Time between attempts

### 10. Accessory Progression Tracking
For key accessories, track progression like main lifts:
- PR weights on important accessories (e.g., close grip bench, front squat)
- Sets/reps over time

## Implementation Suggestion

Start simple! Pick 2-3 that seem most valuable:

**Recommended Starting Point:**
1. Weekly Training Reflection (most bang for buck)
2. Bodyweight (easy to track, very useful)
3. Readiness Score (helps with autoregulation)

**Add these as new columns in your Excel sheet:**
- "Week Feel" (1-5)
- "Bodyweight" (kg)
- "Readiness" (1-10, pre-session)
- "Notes" (free text for reflections)

The dashboard can be updated to visualize these when you have the data!
